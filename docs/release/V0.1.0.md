# NEMESIS Desktop v0.1.0

NEMESIS v0.1.0 is the first source-visible macOS alpha for bounded, witnessed local missions.

## Platform

- macOS 14 or later
- Apple Silicon (`arm64`)
- Local `/usr/bin/git`, `/usr/bin/python3`, `/bin/cat`, and `/usr/bin/sandbox-exec` commands used by the bounded fixture

No Windows, Linux, mobile, web, hosted service, or remote-public daemon artifact is included.

## Assets

- `NEMESIS-Desktop-v0.1.0-macos-arm64.zip` — app bundle and required local backend resources
- `release-manifest.json` — source commit/tree, platform, signing state, size, and SHA-256 of the app archive
- `SHA256SUMS` — SHA-256 checks for the app archive and manifest

The app bundle also contains NEMESIS's Apache-2.0 license and generated third-party notices for the shipped Rust and npm dependency code. The [dependency license review](DEPENDENCY_LICENSE_REVIEW.md) records the generation policy and limits.

## Verify and install

Download all three assets into one directory:

```sh
shasum -a 256 -c SHA256SUMS
ditto -x -k NEMESIS-Desktop-v0.1.0-macos-arm64.zip .
codesign --verify --deep --strict --verbose=2 "NEMESIS Desktop.app"
```

The app is ad-hoc signed and is **not notarized**. Gatekeeper rejection is expected for downloaded bytes because the Apple Developer membership needed for Developer ID signing and notarization is inactive. Prefer building from reviewed source. If you deliberately trust the checksum-verified archive, use macOS **Privacy & Security → Open Anyway**. That override is not signing or notarization evidence.

Launch:

```sh
open "NEMESIS Desktop.app"
```

The witnessed mission uses a disposable repository and local NEMESIS home. Receipt signing may request access to a local Keychain item.

## What this release demonstrates

- Untrusted workers propose; they do not own authoritative mission state or completion.
- Core restart recovers the acknowledged mission state from durable records.
- Final completion evidence is bound to the final source digest.
- A standalone verifier accepts the valid local receipt.
- Protected receipt mutation is rejected.
- The distributed app contains the prebuilt local backend needed to run that bounded fixture without a source checkout.

Re-run the source gate:

```sh
./scripts/verify_complete.sh
```

The full gate includes a local Tart/Apple Virtualization.framework hardening lane that is not available on ordinary GitHub-hosted runners. Portable hosted checks remain separate and do not report that host-only boundary as green.

## Known limitations and non-claims

- Independent external security review remains `[NEEDS-HUMAN]`.
- GNAT 14.2.1 emits retained deployment-target override warnings on the observed macOS 26 toolchain combination.
- The VZ result depends on the recorded local `anubis-xcode` image and host assumptions.
- Model-token replay is not claimed; replay reconstructs recorded authoritative state and decisions.
- No Developer ID signature, notarization, Gatekeeper approval, App Store listing, package registration, legal clearance, or uniqueness of the NEMESIS name is claimed.
